# Website Examples

一套精心设计的网站模板集合，可用于项目伪装站、演示展示或学习参考。

## 模板列表

### 云盘类网站

#### 1. CloudDrive（现代简洁风格）
- **目录**: `cloud-drive/`
- **风格**: 现代、简洁、渐变色设计
- **页面**: 首页、登录页、仪表盘、定价页
- **特点**:
  - 响应式设计
  - 流畅的动画效果
  - 文件管理界面

#### 2. NetDisk（企业风格）
- **目录**: `net-disk/`
- **风格**: 专业、商务、蓝色主调
- **页面**: 首页、登录页、控制台
- **特点**:
  - 企业级UI设计
  - 团队协作界面
  - 数据统计仪表盘

---

### 游戏类网站

#### 3. GameZone（游戏门户）
- **目录**: `game-zone/`
- **风格**: 深色主题、霓虹效果
- **页面**: 首页、登录页、游戏库
- **特点**:
  - 类似Steam风格
  - 游戏卡片展示
  - 热销榜单

#### 4. PlayHub（休闲游戏）
- **目录**: `play-hub/`
- **风格**: 明亮、活泼、彩色
- **页面**: 首页、游戏分类、排行榜
- **特点**:
  - 在线小游戏门户风格
  - 卡通化设计
  - 浮动动画效果

---

### 视频类网站

#### 5. StreamBox（流媒体风格）
- **目录**: `stream-box/`
- **风格**: 深色、影院感、类Netflix
- **页面**: 首页、登录页
- **特点**:
  - 流媒体平台设计
  - 内容轮播
  - 分类内容展示

#### 6. VideoPortal（视频门户）
- **目录**: `video-portal/`
- **风格**: 明亮、门户风格、类B站/优酷
- **页面**: 首页、频道导航、排行榜
- **特点**:
  - 中式视频门户风格
  - 多分类展示
  - 番剧/电影/综艺分区

---

## 使用方法

1. 选择需要的模板目录
2. 直接部署到Web服务器或打开`index.html`预览
3. 根据需要修改内容、颜色、图片等

## 技术栈

- HTML5
- CSS3 (Flexbox, Grid, 动画)
- Vanilla JavaScript
- Google Fonts

## 特性

- 纯静态页面，无需后端
- 响应式设计，支持移动端
- 现代化UI/UX设计
- 可自定义主题色
- 无外部依赖
